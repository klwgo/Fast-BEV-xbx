# 车位类型补充与模型处理建议

## 背景
当前调研已覆盖常见车位（车位线车位：平行/垂直/斜列；空间车位：车-车、车-墙、车-柱围合）与特殊车位（机械、异形、尺寸异常、断头路、特殊地面、无障碍/充电桩等），并补充了环境属性（障碍物、光照/天气、标线状态、几何干扰、传感器干扰）。

## 仍需补充的车位/场景类型
- 串联/双列车位：两车前后串联或超长车位，边界与可泊深度与普通单车位差异大。
- 弧形/弯道侧方车位：靠弧形路缘设置的侧向车位，车位线呈曲线或分段折线。
- 软隔离/临时车位：由锥桶、路障、链条等临时设施划定的可变车位，边界不固定。
- 空间车位补充围合：车-绿化带/围栏/矮墩围合的空间车位，边界材质与高度变化大。
- 大尺寸/专用车位：大客车/货车车位或摩托车专用车位，尺寸与比例与乘用车位不同。

## 模型处理建议（按类型/场景）
| 类型/场景 | 关键风险 | 模型处理建议 |
| --- | --- | --- |
| 车位线车位（平行/垂直/斜列） | 标线磨损、阴影、局部遮挡 | 扩充退化标线数据；在检测头加入方向角回归；使用边界分割辅助定位顶点；多尺度/长宽比先验覆盖30°/45°/60°斜列 |
| 空间车位（车/墙/柱/绿化带围合） | 边界由障碍物定义，遮挡/错检 | 将车位边界统一为可见边+补全边的多边形表示；检测/分割围合物实例并做关系推理（边界由最近两物体生成）；加入占用时序跟踪减少临时遮挡误报 |
| 弧形/弯道侧方车位 | 曲线或折线边界，直线假设失效 | 支持曲线标注（多点折线或Bezier控制点）；在头部使用基于关键点序列的拟合而非固定四点；曲线合成数据增广（弧形路缘、斜坡） |
| 串联/超长车位 | 纵深超出常规，易被拆分/截断 | 解耦长宽回归，上限放宽；引入“串联”类别或长度分桶；基于上下文线索的两车位联合判定（双槽关系约束）；评估阶段按可泊长度过滤 |
| 大尺寸/专用车位（客车/货车/摩托） | 尺寸分布偏移，尺度/比例置信度下降 | 针对大车/小车位分别设先验锚比；类别标签区分专用车位；在BEV特征上使用自适应ROI（Deformable）以适配极端长宽比 |
| 异形/非标准几何车位 | 边界不规则、缺角 | 采用实例分割或顶点序列表达；对缺角/凹多边形做最小可泊区域计算；训练中加入随机裁切/缺边增广 |
| 机械车位 | 结构杆件/高反光导致伪边界 | 针对机械结构增加几何模板匹配特征或轻量分类分支；使用偏振/多曝光或HDR增强缓解反光；训练时标注“不可泊”状态避免误用 |
| 断头路车位 | 单入口、前方刚体封闭 | 结合自由空间/可行驶区域分割，强制验证前向安全余量；路径可行性评分作为可用性判决；多帧融合确认出口无遮挡 |
| 特殊地面材质（砖石/草砖/反光面） | 纹理干扰，标线对比度低 | 采用风格迁移或弱光/高反光增广；加入地面法线或高度先验（若有深度）；可增加简单纹理抑制模块（局部对比度归一） |
| 软隔离/临时车位 | 边界可移动、时效性 | 对锥桶/路障实例做显式检测并参与边界推理；多帧一致性检查，需稳定存在才生成车位；支持手动/高置信度触发的“临时车位模式” |
| 无障碍/充电桩/预留车位 | 需要语义识别与可用性区分 | 增加语义属性分类（无障碍/充电/预留），与占用状态解耦；对充电桩、标识LOGO做小目标检测或模板匹配；策略上支持配置化过滤/优先级 |
